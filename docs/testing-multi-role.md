# 一人で管理者・講師・生徒を兼ねてテストする手順

Mckoy は招待制・パスキー認証のため、利用者が自分一人しかいない状態でも、
別アカウントを作ることで管理者・講師・生徒それぞれの挙動を確認できる。

## 前提

- 招待はメール自動送信をしていない。招待URLはその場で画面に表示されるだけなので、
  実在しないメールアドレスでも（ユニークでさえあれば）招待・登録できる。
- Gmailの `+` エイリアス（例: `you+teacher@gmail.com` / `you+student@gmail.com`）を使うと、
  同じ受信箱宛の別メールアドレスとして複数アカウントを作れる（メール到達は不要）。
- 同一講座の中で講師と生徒を同時に兼ねることはできない
  （`course_memberships` は 1ユーザー・1講座につき1行）。役割ごとに別アカウントが必要。
- ブラウザ/OSのパスキーマネージャは1サイトに複数のパスキー（アカウント）を保存できる。
  ログイン画面の「パスキーでログイン」を押すとアカウント選択のピッカーが出る。
  同時に複数アカウントでログインしておきたい場合はシークレットウィンドウ／別ブラウザ
  プロファイルを使う（Cookieセッションは1ブラウザプロファイルにつき1アカウントのため）。

## 手順

1. **管理者としてログイン**（初期構築時に `seed-admin.mjs` で発行した招待URLで登録済み）。

2. **講師アカウントを作る**
   - ホーム画面の「招待管理」（`/admin/invitations`、管理者のみ表示）を開く
   - 氏名・メールアドレス（例: `you+teacher@gmail.com`）を入力し、「講師資格（can_teach）を付与」
     にチェックして「招待URLを発行」
   - 発行された招待URLを開き、別のパスキーで登録する
   - → 管理者権限を持たない「講師資格あり」アカウントの完成

3. **講師として講座を作る**
   - 手順2のアカウントでログインし直す
   - 「講座一覧」→「新しい講座を作成」
   - 作成すると自動的にその講座の active instructor になる（講座編集・生徒招待・
     参加承認・課題/お知らせ作成が可能になる）

4. **生徒アカウントを作る**
   - 手順3の講座の詳細ページ →「生徒を招待」
   - 氏名・メールアドレス（例: `you+student@gmail.com`）を入力して招待URLを発行
   - 発行された招待URLを開き、また別のパスキーで登録する
   - → 講師からの招待なので承認不要でその講座の active student として即参加完了

これで「管理者」「講師（非管理者）」「生徒」の3つの独立したアカウントが揃う。

## 参加申請フロー（生徒からの申請）を試す場合

手順4は「講師からの招待」なので即active になる。「生徒からの参加申請 → 講師が承認」
の流れを試したい場合は、別の講座の詳細ページで生徒アカウントから直接「参加申請」ボタンを
押す（招待なし）。`pending` の membership ができるので、講師アカウント側でその講座の
メンバー一覧から承認／拒否できる。

## 可視性（visibility）を試す場合

生徒アカウントで小説を投稿する際、公開範囲（講師のみ／講座メンバー／全員）を変えて、
別の生徒アカウント・別講座の講師アカウント・管理者アカウントそれぞれから見え方が
変わることを確認する。
